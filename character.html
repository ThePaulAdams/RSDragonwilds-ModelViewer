Edit your character

Set your spellbooks, unlock recipes and set skill levels in your RuneScape: Dragonwilds character save. Everything happens in your browser: your save is never uploaded.

Your characters are in this folder. Paste it into the address bar of the folder picker:

%LOCALAPPDATA%\RSDragonwilds\Saved\SaveCharacters

This browser can't save back to the file directly, so edited saves are downloaded instead. Chrome or Edge can save in place.

SpellbooksDrag spells onto all four spell wheels, see the rune cost of each book, unlock any spell.
RecipesSearch every recipe, filter by station, unlock one, a whole station or everything at once.
SkillsSet any skill by level or XP, see progress to the next level, or set every skill at once.
InventoryAdd any item, change amounts, repair, move things between bags. Shortcuts follow their item.

How to use the save editor

  1. Close the game (or at least go back to the main menu). The game writes your character when it saves, so it would overwrite your edits.
  2. Click Open characters folder and pick %LOCALAPPDATA%\RSDragonwilds\Saved\SaveCharacters, then click a character. Or open a single file.
  3. Make your changes. Ctrl+Z undoes, Ctrl+Y redoes. The Changes tab lists everything you changed.
  4. Click Save (Ctrl+S). The first time, a copy of the original goes into an Ashenfallen backups folder next to your saves (and into this browser). Then only the parts you changed are written.
  5. Start the game and load your character.

The game also keeps its own .json.backup of the previous save. If something ever goes wrong, use Restore under Backups on the left, or copy a backup back by hand.

In Firefox, Safari and Brave (unless brave://flags/#file-system-access-api is on), the edited save is downloaded instead: put it in the SaveCharacters folder, replacing the old file.
